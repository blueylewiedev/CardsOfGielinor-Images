# Cards of Gielinor: images

The card pictures for the [Cards of Gielinor](https://github.com/blueylewiedev/CardsOfGielinor)
card browser website. Nothing else lives here, and nothing here is needed to run the plugin.

The pictures are taken from the [RuneScape Wiki](https://runescape.wiki/) and are available under
the [Creative Commons Attribution-NonCommercial-ShareAlike 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/)
licence (CC BY-NC-SA). `images.json` lists the wiki file each picture came from, so every one can be
traced to its file page on the wiki, which names its source and author. RuneScape and its artwork belong
to Jagex Ltd; this is an unofficial fan project.

They are made by `dev/build_site.py` and `dev/site_images.py` in the main repository (trimmed, scaled
and centred on a canvas of one size), so they are rewritten whenever that is run again.
